# phần 3: phân tích lỗi chương trình ban đầu

- nguyên nhân gốc rễ: phép chia nguyên (integer division). trong c, phép chia giữa hai số nguyên (như a + b + c là int và 3 là int) sẽ luôn trả về một số nguyên. phần thập phân sẽ bị cắt bỏ (truncate) hoàn toàn.

- lỗi kiểu dữ liệu: biến avg được khai báo là int nên dù phép chia có ra số thực thì nó cũng không thể chứa được số thực.

- lỗi định dạng in: dùng %d (dành cho số nguyên) thay vì %f (dành cho số thực).

# phần 4: code sau khi tự sửa
```html
#include <stdio.h>

int main() {
    int a, b, c;
    float avg; // đổi sang float để lưu số thực

    printf("Nhap 3 diem: ");
    scanf("%d%d%d", &a, &b, &c);

    // Ép kiểu hoặc chia cho 3.0 để thực hiện phép chia số thực
    avg = (float)(a + b + c) / 3; 

    // Dùng %.1f để in ra 1 chữ số thập phân
    printf("Diem trung binh: %.1f", avg);

    return 0;
}

```

# phần 5: giải thích phép chia nguyên và chia số thực
- phép chia nguyên: chỉ áp dụng khi cả tử số và mẫu số đều là số nguyên. kết quả sẽ bị cắt bỏ phần thập phân (không làm tròn). ví dụ: 5 / 2 sẽ bằng 2 chứ không phải 2.5.

- phép chia số thực: xảy ra khi có ít nhất một toán hạng là số thực (float/double). kết quả sẽ giữ lại phần thập phân. ví dụ: 5 / 2.0 hoặc (float)5 / 2 sẽ bằng 2.5.

# phần 6: ví dụ mới chứng minh đã hiểu bài

bài toán: tính trung bình cộng của 3 số: 4, 4, 5.

- nếu dùng code cũ (chia nguyên): (4 + 4 + 5) / 3 -> 13 / 3 -> kết quả là 4 (sai, mất 0.33).

- nếu dùng code mới (chia thực): (float)(4 + 4 + 5) / 3 -> 13.0 / 3 -> kết quả là 4.3 (đúng).
